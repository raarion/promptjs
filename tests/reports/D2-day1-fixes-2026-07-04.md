## Detail per perbaikan

### 🔴 BUG-1 — `muatulang` / `kembali` (fix 1-baris, PUNCAK)
- **Akar:** `allTypes` di `_validateNodeTypes` (`src/compiler/promptjs-compiler.js`) tidak memuat `MuatUlangStatement`/`KembaliStatement` → node ditolak SEBELUM emitter (E5001), padahal emitter siap (`statements.js:1695/1707`).
- **Fix:** tambah 2 tipe ke `allTypes`.
- **Bukti codegen:** `muatulang` → `window.location.reload();` · `kembali` → `window.history.back();` · alias `reload`/`back` juga.

### 🔴 BUG-2 & 🔴 BUG-4 — parsing selector (satu akar)
- **Akar:** `_tokenizeSelector` (`src/lexer/promptjs-lexer.js`) membaca nama tag sampai `.`/`#` saja → `[...]` dan spasi ikut masuk ke tag (`"masukan[...]"`, `"tombol "`); atribut tak pernah ditokenisasi; parser (`_parseSelector`) meneruskan `attributes: []` hardcoded.
- **Fix (lexer):** tag/class/id berhenti di `.`, `#`, `[`, dan whitespace; parse blok `[key]`/`[key="v"]`/`[key='v']`/`[key=v]` → `attributes[]`.
- **Fix (parser):** teruskan `sel.attributes` sebagai `AttributeNode` + `Literal` → jalur emitter `emitSafeAttribute` (S-4 aman terhadap `on*`/URL).
- **Bukti:** `masukan[placeholder="ketik"]` → `createElement("input")` + `__safeAttr(el,"placeholder","ketik")`; `tombol #muat` → `createElement("button")` (tanpa spasi). Regresi `tombol#muat`, `div.a#b`, `masukan` tetap benar.

### 🔴 BUG-3 — W4101 false-positive fetch auto-state
- **Akar:** inline fetch `ambil dari "url" ke <target>` = `AmbilLuarStatement` dengan `bindTarget`. Emitter menulis `<target>`, `<target>_memuat`, `<target>_galat` via `__setState`, tapi resolver tak menandai penggunaan implisit ini → W4101 "tak dipakai" + saran "hapus deklarasi" yang BERBAHAYA.
- **Fix:** `visitAmbilLuarStatement` memanggil `_markFetchAutoStateUsed()` untuk ketiga simbol (read+write). Simbol tak dideklarasikan diabaikan (emitter sudah `typeof`-guard).
- **Bukti:** demo F3/F4 → **0 warning**; deklarasi yang benar-benar tak dipakai TETAP W4101.

### 🟡 INK-1 — severity E4009
- **Kebijakan owner (dipilih: b):** event tak dikenal bersifat **non-fatal** (emitter tetap `addEventListener(<event>)` sebagai escape-hatch custom event). E4009 tetap di bucket `warnings`, tetapi kini `severity:'warning'` (konsisten). Kode & pesan dipertahankan agar test/tooling lama tak putus (`tests/v5-boundary.test.js` tetap hijau).

### 🟡 DX-1 — E2020
- **Fix pesan:** tampilkan teks sumber (`"Buat"`) bukan token internal (`TK_BUAT`) + Saran actionable.
- **Fix cascade:** parser set `hadFatalParseError`; engine set `resolver._suppressUndeclaredCascade`; `visitIdentifier` tak lagi emit E3001 palsu (mis. `span tidak dideklarasikan`).
- **Fix dok:** `error-codes.js` + `docs/reference/error-codes.md` E2020 diselaraskan dari "Indentasi tidak konsisten" → "Token tidak terduga".

### 🟡 DX-2 — transisi tanpa kunci
- **Fix:** sebelum `delete node.transitionName`, resolver push **W3004** (`"dengan transisi <name>" diabaikan karena tanpa "dengan kunci"`). Kode baru terdaftar di `error-codes.js` + docs. Dengan kunci → transisi aktif, tanpa W3004.

### 🟢 DX-3 — kunci duplikat
- **Fix:** kunci duplikat hanya bisa dideteksi saat runtime (data-driven). `__keyedList` (`runtime.js`) emit `console.warn('[PromptJS][W-keyed-dup] ...')` SEKALI per render saat men-disambiguasi `key__index`. Disambiguasi aman tetap dipertahankan.
